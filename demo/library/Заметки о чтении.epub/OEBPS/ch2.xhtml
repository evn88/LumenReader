Глава 2. Код в книгах

Чтение — это разговор с автором, растянутый во времени. Хорошая книга задаёт вопросы раньше, чем мы успеваем их сформулировать, а хорошая читалка не мешает этому разговору: не отвлекает, не торопит и помнит, где мы остановились. Электронный текст позволяет менять размер шрифта, тему и поля, сохраняя структуру книги — главы, сноски, иллюстрации и примеры кода.

import Foundation

struct Note: Codable {
    let page: Int
    let text: String
}

func load(from url: URL) throws -> [Note] {
    let data = try Data(contentsOf: url)
    return try JSONDecoder().decode([Note].self, from: data)
}
